# Сайт Loca Loca

Каталог `site/` содержит статический сайт проекта, который публикуется через GitHub Pages. Здесь находятся публичное описание приложения, иллюстрации и визуальные материалы; серверная логика приложения в сайт не входит.

## Состав сайта

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная страница: назначение Loca Loca, основные возможности, пример использования, сведения о хранении данных, установка и ответы на частые вопросы |
| `styles.css` | Стили, адаптивная компоновка, оформление секций и элементов страницы |

Сайт не использует отдельный frontend framework или сборщик: публикуются исходные HTML и CSS.

## Локальный просмотр

Из корня репозитория можно запустить простой локальный HTTP-сервер:

```powershell
py -m http.server 8000 --directory site
```

Затем откройте [http://localhost:8000](http://localhost:8000). Для завершения сервера нажмите Ctrl+C в окне PowerShell.

После изменения HTML или CSS обновите страницу браузера. Проверяйте не только широкое окно, но и мобильную ширину: сайт должен оставаться читаемым без горизонтальной прокрутки.

## Разработка и актуальность содержимого

- Текст о функциях приложения должен соответствовать фактическим возможностям WinUI-клиента и API. Сверяйтесь с корневым [README.md](../README.md).
- При описании синхронизации учитывайте фактическую архитектуру: клиент обращается к API, а структурированные данные и фотографии хранятся в общей Supabase PostgreSQL.
- Новые фотографии сохраняются в столбцах `bytea` таблиц `photos` и `user_map_place_photos`. Временные локальные копии для внешнего просмотра не являются основным хранилищем.
- Не размещайте на сайте реальные учётные данные, строки подключения, токены, приватные пользовательские фотографии или другие секреты.

### Изображения маскота

Главная страница использует изображение маскота из `LocaLoca/Assets/Mascot/` основной ветки репозитория через URL GitHub Raw. Если файл переименован или перенесён, обновите ссылку и альтернативный текст в `index.html`.

Фоновые декоративные элементы страницы и изображение персонажа являются отдельными элементами разметки и стилей. При замене маскота не требуется менять CSS фона, если визуальная композиция остаётся прежней.

## Публикация через GitHub Pages

Workflow [\.github/workflows/pages.yml](../.github/workflows/pages.yml):

- запускается при push в `main`, если изменились файлы `site/**`, сам workflow или `LocaLoca/Assets/**`;
- также поддерживает ручной запуск через `workflow_dispatch`;
- загружает каталог `site/` как Pages artifact и публикует его через GitHub Pages.

Для автоматической публикации изменения должны попасть в `main`, а GitHub Pages должен быть настроен для GitHub Actions. Статус деплоя и опубликованный URL доступны в Actions и в окружении `github-pages`.

## Проверка перед публикацией

Перед отправкой изменений проверь:

1. Страница открывается локально и все изображения загружаются.
2. Внутренние и внешние ссылки ведут на ожидаемые адреса.
3. Текст не обещает возможностей, которых ещё нет в приложении.
4. На мобильной ширине нет обрезанных секций и горизонтальной прокрутки.
5. В diff отсутствуют секреты и персональные данные.
