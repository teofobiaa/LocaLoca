# Установщик Loca Loca для Windows

Для сборки установщика выполните в PowerShell из корня репозитория:

```powershell
.\tools\Build-Installer.ps1
```

Нужны стабильный .NET 10 SDK, компоненты сборки WinUI 3/Windows App SDK и Inno Setup 6 или 7. Готовый файл появится в `Builds\Installer\LocaLoca-Setup.exe`.

Установщик устанавливает приложение только для текущего пользователя, не требует прав администратора и перед установкой спрашивает IP-адрес или имя хоста PostgreSQL, порт, имя базы, имя пользователя, пароль и режим SSL. Параметры подключения записываются в `%LOCALAPPDATA%\LocaLoca\server-config.json`; файл содержит пароль и не должен публиковаться или передаваться посторонним. Установщик не создаёт базу данных и не применяет SQL-схему — база и таблицы должны быть заранее подготовлены.
