# Установщик Loca Loca для Windows

Для сборки установщика выполните в PowerShell из корня репозитория:

```powershell
.\tools\Build-Installer.ps1
```

Нужны стабильный .NET 10 SDK, компоненты сборки WinUI 3/Windows App SDK и Inno Setup 6 или 7. Готовый файл появится в `Builds\Installer\LocaLoca-Setup.exe`.

Установщик предназначен для Windows x64, устанавливает приложение только для текущего пользователя и не требует прав администратора. После установки он может запустить приложение; при первом запуске откроется мастер подключения к удалённой PostgreSQL. Хост, порт, имя базы, имя пользователя и SSL-режим уже заполнены. Введите пароль базы и нажмите «Сохранить и проверить подключение».

Приложение проверяет доступность API и PostgreSQL перед показом формы входа. Пароль подключения сохраняется в `%LOCALAPPDATA%\LocaLoca\server-config.json` на компьютере пользователя; он не вшивается в установщик. Если проверка не проходит, мастер оставляет параметры доступными для исправления и повторной проверки.

До установки на удалённом сервере должны быть созданы база и пользователь, разрешены подключения с компьютера пользователя и применена схема Loca Loca. Установщик не создаёт базу на хостинге и не запускает SQL-миграции. `127.0.0.1:5181` — локальный API, а не адрес удалённого PostgreSQL.
