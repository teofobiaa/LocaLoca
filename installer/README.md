# Установщик Loca Loca для Windows

Для сборки установщика выполните в PowerShell из корня репозитория:

```powershell
.\tools\Build-Installer.ps1
```

Нужны стабильный .NET 10 SDK, компоненты сборки WinUI 3/Windows App SDK и Inno Setup 6 или 7. Готовый файл появится в `Builds\Installer\LocaLoca-Setup.exe`.

Установщик устанавливает клиент только для текущего пользователя, не требует прав администратора, не спрашивает IP-адрес или реквизиты подключения и не записывает общий пароль в дистрибутив. Приложение уже настроено обращаться к локальному API на `127.0.0.1:5181`.

**Важно:** адрес API `127.0.0.1` и адрес PostgreSQL — разные вещи. Установщик приложения не устанавливает и не настраивает PostgreSQL. Чтобы база работала на этом же компьютере, предварительно установите PostgreSQL, настройте локальную базу и создайте конфигурацию командой `tools\Setup-PostgreSQL.ps1`. Скрипт использует `127.0.0.1` для PostgreSQL и сохраняет локальный пароль в `%LOCALAPPDATA%\LocaLoca\server-config.json`. Для первоначальной настройки он запросит пароль администратора PostgreSQL. Имеющийся файл конфигурации установщик не перезаписывает.

Таким образом, само приложение запускается без ввода IP пользователем, когда на компьютере уже настроена локальная база. Полностью автоматическая установка «на чистом компьютере без вопросов» потребует дополнительно включить установку и первичную настройку PostgreSQL; текущий установщик этого не делает.
