# Каталог тест-кейсов Loca Loca

**Статус:** проектирование, версия 1.0.  
**Обозначения:** P0 — блокирующий сценарий; P1 — важный; P2 — дополнительный.  
Фактические тесты ещё не реализованы: этот документ задаёт проверяемые условия и ожидаемое поведение.

## 9. Правила фиксации результата

Для каждого выполненного кейса сохранять: ID, версию/commit, окружение, тестовые данные, фактический результат, ожидаемый результат, статус Pass/Fail/Blocked, ссылку на лог или скриншот и связанный issue при Fail.

Кейс нельзя помечать Pass, если проверен только HTTP-статус: необходимо проверить состояние БД и отсутствие побочных изменений там, где сценарий меняет данные.
