# Loca Loca

Настольное приложение для учёта путешествий: можно вести список посещённых мест, сохранять заметки и фотографии, а также отмечать точки на карте.

Приложение работает с локальной базой PostgreSQL. WinUI-клиент запускает локальный API, а API подключается к базе на этом же компьютере. Интернет нужен для карты OpenStreetMap и для первичной загрузки установщика PostgreSQL/WebView2, если они ещё не установлены.

## Что нужно для запуска

- Windows 10 версии 22H2 или Windows 11, x64.
- Интернет при первой установке, если PostgreSQL или WebView2 Runtime ещё не установлены.
- Права администратора Windows только на этапе установки PostgreSQL и системного WebView2 Runtime.

.NET 10 и Windows App SDK уже входят в self-contained сборку приложения. Пользователю не нужно устанавливать Visual Studio, .NET SDK, Inno Setup, pgAdmin или вручную запускать PowerShell.

## Установка на новом компьютере

1. Запусти Builds\Installer\LocaLoca-Setup.exe.
2. Подтверди запрос Windows на установку системных компонентов.
3. Установщик проверит WebView2 Runtime и установит его с официального сервера Microsoft, только если он отсутствует.
4. Если конфигурации Loca Loca ещё нет, установщик загрузит и установит PostgreSQL 17.11 для Windows x64 с сервера EnterpriseDB, создаст отдельную службу Windows LocaLocaPostgreSQL17, базу loca_loca, пользователя БД loca_app, применит схему, начальные данные и SQL-миграции.
5. Установщик сохранит строку подключения в %LOCALAPPDATA%\LocaLoca\server-config.json и предложит запустить приложение.

PostgreSQL работает как фоновая служба Windows и автоматически запускается вместе с системой. Установка PostgreSQL требует прав администратора; само приложение устанавливается в профиль пользователя и при обычном запуске не требует повышенных прав.

Установщик не меняет существующий файл server-config.json и не переустанавливает уже настроенную пользовательскую базу. На компьютере с существующей конфигурацией он проверит/установит WebView2, сохранит настройки базы и продолжит установку приложения.

### Безопасность и данные

- Для каждой новой установки генерируются уникальные случайные пароли PostgreSQL и пользователя приложения.
- Пароль администратора PostgreSQL используется только при первоначальной настройке и не записывается в конфигурацию приложения.
- Временный файл восстановления установки хранится в %ProgramData%\LocaLoca\Bootstrap с доступом только для Administrators и SYSTEM; после успешной настройки он удаляется.
- PostgreSQL слушает локальный адрес 127.0.0.1; база не открывается для прямого доступа из локальной сети.
- Удаление Loca Loca не удаляет базу PostgreSQL, службу, фотографии или настройки пользователя. Это защищает данные от случайной потери; для полного удаления базы используйте отдельную административную процедуру после резервного копирования.

База локальная: данные каждого компьютера хранятся на нём и автоматически не синхронизируются с другими компьютерами.

## Экспорт полного каталога достопримечательностей

`database/02_seed.sql` уже содержит полный каталог из 44 достопримечательностей, сформированный из резервной копии PostgreSQL от 06.11.2026.

В seed включены только справочные данные: достопримечательности, описания, история, координаты, категории, города и страны. Пользователи, хэши паролей, посещения, фотографии и личные заметки не переносятся.

Для сборки установщика повторный экспорт не нужен: `tools\Build-Installer.ps1` проверит наличие заголовка полного каталога и соберёт установщик с 44 местами.

Сценарий `tools\Export-AttractionsSeed.ps1` оставлен для будущего обновления каталога из активной базы данных. Перед его запуском необходимо убедиться, что строка подключения указывает именно на базу с полным каталогом.
 
## Первый запуск из исходников

Для разработки можно настроить PostgreSQL вручную:

1. Если PostgreSQL ещё не настроен для приложения, открой PowerShell в корне проекта и запусти:

   ~~~powershell
   .\tools\Setup-PostgreSQL.ps1
   ~~~

   Скрипт создаёт локальную базу и пользователя приложения, применяет схему и сохраняет строку подключения в %LOCALAPPDATA%\LocaLoca\server-config.json. При запросе введи пароль администратора PostgreSQL. Если база уже настроена, не запускай скрипт повторно без необходимости: он меняет пароль пользователя приложения.

2. Открой LocaLoca.sln в Visual Studio и дождись восстановления NuGet-пакетов.
3. Выбери конфигурацию Debug, платформу x64 и профиль Unpackaged, если он отображается.
4. При необходимости опубликуй локальный API:

   ~~~powershell
   .\tools\Publish-LocalApi.ps1
   ~~~

5. Запусти приложение клавишей F5.

При запуске клиент проверяет API по адресу http://127.0.0.1:5181. Если служба PostgreSQL остановлена, запусти её в оснастке «Службы» Windows и нажми «Повторить подключение» в приложении.

## Возможности

- регистрация и вход;
- каталог достопримечательностей с поиском и фильтром;
- список посещённых мест и «Хочу посетить»;
- даты, оценки, заметки и впечатления о поездках;
- фотографии к посещениям и личным точкам;
- статистика и карта с местами из каталога и собственными отметками.

## Сборка для Windows

Из PowerShell в корне проекта запусти:

~~~powershell
.\tools\Build-Windows.ps1
~~~

Готовая сборка появится в Builds\Windows. Клиент и API публикуются для Windows x64 вместе с необходимыми компонентами .NET и Windows App SDK.

Если запускаешь приложение прямо из Builds\Windows, создай ярлык на LocaLoca.exe. Не перемещай этот файл отдельно: рядом должна оставаться папка Server с локальным API.

### Сборка установщика

Для создания установщика дополнительно установи Inno Setup 6.3 или новее. Из PowerShell в корне проекта запусти:

~~~powershell
.\tools\Build-Installer.ps1
~~~

Скрипт сначала собирает приложение и локальный API, затем создаёт Builds\Installer\LocaLoca-Setup.exe. Готовый установщик включает клиент, локальный API, SQL-файлы и сценарий первичной настройки PostgreSQL/WebView2.

На целевом компьютере установщик скачивает PostgreSQL и WebView2 только при необходимости, поэтому для первого запуска требуется интернет. Сборка самого приложения по-прежнему требует стабильный .NET 10 SDK, компоненты Windows App SDK/Windows SDK и Inno Setup.

## Если что-то не запускается

- Не удаётся подключиться к базе. Проверь, что служба LocaLocaPostgreSQL17 запущена и существует %LOCALAPPDATA%\LocaLoca\server-config.json.
- Установка PostgreSQL завершилась ошибкой. Повтори запуск установщика. Временный файл восстановления позволяет продолжить настройку. Не удаляй %ProgramData%\LocaLoca\Bootstrap, пока установка не завершена.
- API не найден. При запуске из исходников выполни .\tools\Publish-LocalApi.ps1, затем запусти приложение снова.
- Проверить API вручную. Открой http://127.0.0.1:5181/health. При успешном подключении ответ содержит "apiConfigured": true и "databaseConnected": true.
- Карта не отображается. Проверь подключение к интернету и наличие WebView2 Runtime.
- NuGet-пакеты не восстанавливаются. Проверь доступ к api.nuget.org и установленные компоненты Visual Studio.

## Данные и резервная копия

Данные приложения находятся в локальной базе PostgreSQL. Фотографии хранятся отдельно в %LOCALAPPDATA%\LocaLoca\Photos. Для полной резервной копии сохрани дамп базы и эту папку с фотографиями.

Схема базы и SQL-миграции находятся в database/. После изменения исходников API запусти .\tools\Publish-LocalApi.ps1, чтобы обновить сервер, который использует клиент.

## Структура проекта

- LocaLoca/ — WinUI-клиент.
- LocaLoca/Assets/ — иконка приложения и изображения маскота.
- Server/LocaLoca.Api/ — исходники локального API.
- database/ — схема, начальные данные и миграции PostgreSQL.
- installer/ — сценарий Inno Setup для Windows-установщика.
- tools/ — скрипты настройки базы, первичной установки зависимостей, публикации API и сборки приложения/установщика.
