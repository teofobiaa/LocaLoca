# Loca Loca

Настольное приложение для учёта путешествий: можно вести список посещённых мест, сохранять заметки и фотографии, а также отмечать точки на карте.

Приложение работает с локальной базой PostgreSQL. WinUI-клиент запускает локальный API, а API подключается к базе на этом же компьютере. Интернет нужен для карты OpenStreetMap.

## Что нужно для запуска

- Windows 10 версии 22H2 или Windows 11, x64.
- PostgreSQL для Windows, запущенный как служба.
- WebView2 Runtime для карты.

Для сборки из исходников также нужны Visual Studio 2026 (18.0 или новее) с компонентами разработки .NET и Windows App SDK, .NET 10 SDK и Windows SDK 10.0.19041.0 или новее. Используется стабильная версия .NET 10.

## Первый запуск

1. Если PostgreSQL ещё не настроен для приложения, открой PowerShell в корне проекта и запусти:

   ```powershell
   .\tools\Setup-PostgreSQL.ps1
   ```

   Скрипт создаёт локальную базу и пользователя приложения, применяет схему и сохраняет строку подключения в `%LOCALAPPDATA%\LocaLoca\server-config.json`. При запросе введи пароль администратора PostgreSQL. Если база уже настроена, не запускай скрипт повторно без необходимости: он меняет пароль пользователя приложения.

2. Открой `LocaLoca.sln` в Visual Studio и дождись восстановления NuGet-пакетов.
3. Выбери конфигурацию `Debug`, платформу `x64` и профиль `Unpackaged`, если он отображается.
4. Запусти приложение клавишей F5.

При запуске клиент проверяет API по адресу `http://127.0.0.1:5181`. Если API ещё не опубликован, сначала выполни:

```powershell
.\tools\Publish-LocalApi.ps1
```

Скрипт размещает сервер в `LocaLoca\Server`. Затем можно запускать приложение из Visual Studio.

## Возможности

- регистрация и вход;
- каталог достопримечательностей с поиском и фильтром;
- список посещённых мест и «Хочу посетить»;
- даты, оценки, заметки и впечатления о поездках;
- фотографии к посещениям и личным точкам;
- статистика и карта с местами из каталога и собственными отметками.

## Сборка для Windows

Из PowerShell в корне проекта запусти:

```powershell
.\tools\Build-Windows.ps1
```

Готовая сборка появится в `Builds\Windows`. Клиент и API публикуются для Windows x64 вместе с необходимыми компонентами .NET и Windows App SDK.

Если запускаешь приложение прямо из `Builds\Windows`, создай ярлык на `LocaLoca.exe`. Не перемещай этот файл отдельно: рядом должна оставаться папка `Server` с локальным API.

При последующих запусках Visual Studio, pgAdmin и `psql` открывать не нужно. Достаточно, чтобы служба PostgreSQL работала в фоне: клиент автоматически запустит локальный API и подключится к базе. Чтобы не запускать службу вручную, настрой для PostgreSQL автоматический запуск вместе с Windows. Если служба остановлена, приложение не сможет подключиться к базе.

### Сборка установщика

Для создания установщика дополнительно установи Inno Setup 6.3 или новее. Из PowerShell в корне проекта запусти:

```powershell
.\tools\Build-Installer.ps1
```

Скрипт сначала собирает приложение и локальный API, затем создаёт `Builds\Installer\LocaLoca-Setup.exe`. Установщик размещает приложение для текущего пользователя, создаёт ярлык в меню «Пуск» и предлагает создать ярлык на рабочем столе и запустить приложение.

Установщик включает клиент и локальный API, но не устанавливает PostgreSQL, не запускает его службу и не копирует файл подключения с паролем. На компьютере запуска заранее настрой PostgreSQL и оставь его службу работающей в фоне. Запись приложения в списке установленных программ Windows использует отдельную иконку установщика. При удалении приложения база, фотографии и настройки пользователя сохраняются.

## Если что-то не запускается

- **Не удаётся подключиться к базе.** Проверь, что служба PostgreSQL запущена и существует файл `%LOCALAPPDATA%\LocaLoca\server-config.json`.
- **API не найден.** Выполни `.\tools\Publish-LocalApi.ps1`, затем запусти приложение снова.
- **Проверить API вручную.** Открой `http://127.0.0.1:5181/health`. При успешном подключении ответ содержит `"apiConfigured": true` и `"databaseConnected": true`.
- **Карта не отображается.** Проверь подключение к интернету и наличие WebView2 Runtime.
- **NuGet-пакеты не восстанавливаются.** Проверь доступ к `api.nuget.org` и установленные компоненты Visual Studio.

## Данные и резервная копия

Данные приложения находятся в локальной базе PostgreSQL. Фотографии хранятся отдельно в `%LOCALAPPDATA%\LocaLoca\Photos`. Для полной резервной копии сохрани дамп базы и эту папку с фотографиями.

Схема базы и SQL-миграции находятся в `database/`. После изменения исходников API запусти `.\tools\Publish-LocalApi.ps1`, чтобы обновить сервер, который использует клиент.

## Структура проекта

- `LocaLoca/` — WinUI-клиент.
- `LocaLoca/Assets/` — иконка приложения и изображения маскота.
- `Server/LocaLoca.Api/` — исходники локального API.
- `database/` — схема, начальные данные и миграции PostgreSQL.
- `installer/` — сценарий Inno Setup для Windows-установщика.
- `tools/` — скрипты настройки базы, публикации API и сборки приложения/установщика.
