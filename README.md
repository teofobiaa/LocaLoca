# Loca Loca

Настольное приложение для учёта путешествий: можно вести список посещённых мест, сохранять заметки и фотографии, а также отмечать точки на карте.

Приложение использует локальную базу PostgreSQL. WinUI-клиент запускает локальный API, а API подключается к базе на этом же компьютере. Установка и обычная работа не требуют отдельного сервера или настройки домашней сети.

## Быстрый старт: инструкция для получателя установщика

Этих шагов достаточно, чтобы установить приложение на новый компьютер:

1. Сохрани полученный файл `LocaLoca-Setup.exe` и запусти его двойным щелчком.
2. Подтверди запрос Windows на установку системных компонентов. Для установки PostgreSQL и некоторых системных компонентов могут потребоваться права администратора.
3. Дождись завершения установки. Если WebView2 Runtime или PostgreSQL ещё не установлены, установщик сам скачает и установит их. На новом компьютере он также создаст локальную базу данных и загрузит стартовый каталог из 44 достопримечательностей.
4. Оставь включённым создание ярлыка на рабочем столе, если мастер установки предлагает этот пункт.
5. Запусти Loca Loca и зарегистрируй собственную учётную запись: придумай логин и пароль. После регистрации можно пользоваться приложением.

**Вручную настраивать IP-адрес, порты, PostgreSQL, сервер или роутер не нужно.** Приложение само подключается к локальным компонентам компьютера. Не нужно устанавливать Visual Studio, .NET SDK, Inno Setup или pgAdmin и запускать команды PowerShell.

### Что потребуется

- Windows 10 версии 22H2 или Windows 11, x64.
- Интернет во время первой установки, если PostgreSQL или WebView2 Runtime отсутствуют. Установщик получает их с официальных серверов EnterpriseDB и Microsoft.
- Интернет для загрузки карты OpenStreetMap. Основные данные приложения хранятся локально.

.NET 10 и Windows App SDK уже входят в self-contained сборку приложения.

## Как устроена локальная установка

- PostgreSQL работает как фоновая служба Windows `LocaLocaPostgreSQL17` и автоматически запускается вместе с системой.
- База данных доступна только на самом компьютере через локальный адрес `127.0.0.1`. Установщик автоматически выбирает свободный порт PostgreSQL в диапазоне 5432–5450.
- Локальный API приложения использует адрес `http://127.0.0.1:5181`.
- Открывать порты на роутере, настраивать IP в приложении или разрешать удалённые подключения к PostgreSQL не требуется.

Если на компьютере уже есть действующая конфигурация Loca Loca в `%LOCALAPPDATA%\LocaLoca\server-config.json`, установщик сохраняет её и не переустанавливает и не сбрасывает настроенную базу. Каталог из 44 достопримечательностей загружается при первоначальном создании новой базы; существующая база автоматически не перезаполняется.

### Безопасность и данные

- Для каждой новой установки генерируются уникальные случайные пароли PostgreSQL и пользователя приложения.
- Пароль администратора PostgreSQL используется только при первоначальной настройке и не записывается в конфигурацию приложения.
- Временный файл восстановления установки хранится в `%ProgramData%\LocaLoca\Bootstrap` с доступом только для Administrators и SYSTEM; после успешной настройки он удаляется.
- PostgreSQL слушает только локальный адрес `127.0.0.1`; база не открывается для прямого доступа из локальной сети.
- Удаление Loca Loca не удаляет базу PostgreSQL, службу, фотографии или настройки пользователя. Это защищает данные от случайной потери; перед полным удалением базы сделай резервную копию.

**Важно:** база локальная. Данные, добавленные на одном компьютере, автоматически не появляются на другом компьютере. Для переноса данных нужна резервная копия и отдельное восстановление.

## Каталог достопримечательностей

`database/02_seed.sql` содержит стартовый каталог из 44 достопримечательностей, подготовленный из резервной копии PostgreSQL от 06.11.2026.

В seed включены только справочные данные: достопримечательности, описания, история, координаты, категории, города и страны. Пользователи, хэши паролей, посещения, фотографии, wishlist и личные заметки из резервной копии не переносятся.

Для сборки установщика повторный экспорт не нужен: `tools\Build-Installer.ps1` проверяет наличие полного каталога. Сценарий `tools\Export-AttractionsSeed.ps1` оставлен для будущего обновления каталога из активной базы данных. Перед его запуском необходимо убедиться, что строка подключения указывает именно на базу с полным каталогом.

## Первый запуск из исходников

Этот раздел нужен только для разработки. Получателю готового установщика выполнять эти действия не требуется.

Для ручной настройки PostgreSQL открой PowerShell в корне проекта и запусти:

~~~powershell
.\tools\Setup-PostgreSQL.ps1
~~~

Скрипт создаёт локальную базу и пользователя приложения, применяет схему и сохраняет строку подключения в `%LOCALAPPDATA%\LocaLoca\server-config.json`. При запросе введи пароль администратора PostgreSQL. Если база уже настроена, не запускай скрипт повторно без необходимости: он меняет пароль пользователя приложения.

Затем:

1. Открой `LocaLoca.sln` в Visual Studio и дождись восстановления NuGet-пакетов.
2. Выбери конфигурацию Debug, платформу x64 и профиль Unpackaged, если он отображается.
3. При необходимости опубликуй локальный API:

   ~~~powershell
   .\tools\Publish-LocalApi.ps1
   ~~~

4. Запусти приложение клавишей F5.

При запуске клиент проверяет API по адресу `http://127.0.0.1:5181`. Если служба PostgreSQL остановлена, запусти её в оснастке «Службы» Windows и нажми «Повторить подключение» в приложении.

## Возможности

- регистрация и вход;
- каталог достопримечательностей с поиском и фильтром;
- список посещённых мест и «Хочу посетить»;
- даты, оценки, заметки и впечатления о поездках;
- фотографии к посещениям и личным точкам;
- статистика и карта с местами из каталога и собственными отметками.

## Сборка для Windows

Из PowerShell в корне проекта запусти:

~~~powershell
.\tools\Build-Windows.ps1
~~~

Готовая сборка появится в `Builds\Windows`. Клиент и API публикуются для Windows x64 вместе с необходимыми компонентами .NET и Windows App SDK.

Если запускаешь приложение прямо из `Builds\Windows`, создай ярлык на `LocaLoca.exe`. Не перемещай этот файл отдельно: рядом должна оставаться папка `Server` с локальным API.

### Сборка установщика

Для создания установщика дополнительно установи Inno Setup 6.3 или новее. Из PowerShell в корне проекта запусти:

~~~powershell
.\tools\Build-Installer.ps1
~~~

Скрипт сначала собирает приложение и локальный API, затем создаёт `Builds\Installer\LocaLoca-Setup.exe`. Готовый установщик включает клиент, локальный API, SQL-файлы и сценарий первичной настройки PostgreSQL/WebView2.

На целевом компьютере установщик скачивает PostgreSQL и WebView2 только при необходимости. Поэтому при первом запуске установщика может потребоваться интернет. Сборка самого приложения по-прежнему требует .NET 10 SDK, компоненты Windows App SDK/Windows SDK и Inno Setup.

## Если что-то не запускается

- **Не удаётся подключиться к базе.** Проверь, что служба `LocaLocaPostgreSQL17` запущена и существует файл `%LOCALAPPDATA%\LocaLoca\server-config.json`.
- **Установка PostgreSQL завершилась ошибкой.** Повтори запуск установщика. Временный файл восстановления позволяет продолжить настройку. Не удаляй `%ProgramData%\LocaLoca\Bootstrap`, пока установка не завершена.
- **API не найден.** При запуске из исходников выполни `.\tools\Publish-LocalApi.ps1`, затем запусти приложение снова.
- **Проверить API вручную.** Открой `http://127.0.0.1:5181/health`. При успешном подключении ответ содержит `"apiConfigured": true` и `"databaseConnected": true`.
- **Карта не отображается.** Проверь подключение к интернету и наличие WebView2 Runtime.
- **NuGet-пакеты не восстанавливаются.** Проверь доступ к `api.nuget.org` и установленные компоненты Visual Studio.

## Данные и резервная копия

Данные приложения находятся в локальной базе PostgreSQL. Фотографии хранятся отдельно в `%LOCALAPPDATA%\LocaLoca\Photos`. Для полной резервной копии сохрани дамп базы и эту папку с фотографиями.

Схема базы и SQL-миграции находятся в `database/`. После изменения исходников API запусти `.\tools\Publish-LocalApi.ps1`, чтобы обновить сервер, который использует клиент.

## Структура проекта

- `LocaLoca/` — WinUI-клиент.
- `LocaLoca/Assets/` — иконка приложения и изображения маскота.
- `Server/LocaLoca.Api/` — исходники локального API.
- `database/` — схема, начальные данные и миграции PostgreSQL.
- `installer/` — сценарий Inno Setup для Windows-установщика.
- `tools/` — скрипты настройки базы, первичной установки зависимостей, публикации API и сборки приложения/установщика.
