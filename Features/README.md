# Совместная функциональность Loca Loca

Эта ветка предназначена для будущего объединения аккаунтов: добавления друзей, приглашений и совместных отметок о посещённых местах.

Основной проект уже использует собственную таблицу `users`, ASP.NET Core API и PostgreSQL. Для дружбы и совместных посещений планируется использовать ту же базу и существующую авторизацию приложения. Внешние социальные платформы, Supabase Auth, сторонние надстройки и дополнительные облачные сервисы для MVP не требуются.

## Статус

Пока это проектирование и отдельная ветка. Схема PostgreSQL, миграции и API production-базы не менялись. Перед реализацией нужно согласовать UX приглашений и правила видимости совместных записей.
