# Как внести вклад в Loca Loca

Спасибо, что хотите помочь! Баги, идеи, правки текста и код — всё это полезно, даже самая мелкая правка.

## С чего начать

- **Нашли баг или есть идея:** создайте [Issue](https://github.com/teofobiaa/LocaLoca/issues). Опишите, что вы делали, что произошло и что ожидали.
- **Не уверены, баг это или нет, или хотите просто обсудить:** пишите в [Discussions](https://github.com/teofobiaa/LocaLoca/discussions).
- **Хотите взяться за задачу:** напишите об этом в Issue, чтобы мы не делали одно и то же дважды.
- **Нашли уязвимость:** не пишите о ней в открытом Issue. Следуйте инструкции в [SECURITY.md](SECURITY.md).

## Как предложить изменение

1. Сделайте fork репозитория и создайте отдельную ветку для одного логически связанного изменения.
2. Внесите изменения и проверьте, что всё работает (см. ниже).
3. Откройте Pull Request и коротко опишите, что изменили и зачем. Укажите, какие проверки запускали и что получилось.

Небольшие и понятные Pull Request проверять проще, чем большие.

## Настройка для разработки

Нужны Windows 10 22H2 или Windows 11 x64, .NET SDK 10, Visual Studio с компонентами WinUI 3, Windows App SDK и Windows SDK, а также WebView2 Runtime. Подробные шаги есть в [README](README.md#для-разработчика).

Кратко:

```powershell
git clone https://github.com/<ваш-ник>/LocaLoca.git
cd LocaLoca
.\tools\Install-CloudDependencies.ps1
```

Откройте `LocaLoca.sln`, выберите `Debug / x64 / Unpackaged` и нажмите F5.

## Тесты

Запуск (нужен Docker Desktop с Linux-контейнерами):

```powershell
dotnet test Tests/LocaLoca.Tests.sln --configuration Release
```

Если вы меняете API или базу данных, добавьте или обновите тесты. Изменение документации не считается проверкой работы. Если меняете WinUI или установщик, проверьте Windows-сборку и основные сценарии вручную.

Подробнее: [Tests/README.md](Tests/README.md).

## Правила

- **Не добавляйте секреты:** пароли, строки подключения, токены, реальные данные пользователей, локальные конфиги и дампы базы.
- **Не выкладывайте секреты** в Issues, Discussions и комментарии.
- **Пишите понятно:** тексты в интерфейсе должны быть короткими и понятными даже новичку. Подробнее: [ACCESSIBILITY.md](ACCESSIBILITY.md).
- **Общайтесь уважительно.** Мы следуем [Кодексу поведения](CODE_OF_CONDUCT.md).

## Лицензия

Отправляя Pull Request, вы соглашаетесь, что ваш вклад будет распространяться на условиях лицензии проекта (см. [LICENSE](LICENSE)).

## Вопросы

Если что-то непонятно, не стесняйтесь спросить в [Discussions](https://github.com/teofobiaa/LocaLoca/discussions). Лучше задать «глупый» вопрос, чем потерять время.
