# Каталог достопримечательностей — партия 04

Дата подготовки: 18 ноября 2026 года. Ветка: `feature/catalog-195-countries-reference`. Добавлено 10 объектов в 10 ранее не представленных государствах.

## Методика

Описания и исторические сведения составлены по материалам Центра всемирного наследия ЮНЕСКО. Координаты взяты из таблиц географических данных UNESCO World Heritage Centre, переведены из DMS в десятичные градусы и округлены до 6 знаков. Для крупных археологических территорий, городских ансамблей и охраняемых комплексов координата является репрезентативной точкой объекта, а не обязательно входом.

## Примечания по географической привязке и классификации

- Для Бру-на-Бойн в качестве локальности указано Донор (Donore), рядом с археологическим комплексом; координата соответствует географической точке объекта UNESCO.
- Для Рильского монастыря, Ахпата, Студеницы и Бутринта использованы названия поселений/локальностей, связанные непосредственно с объектами, а не удалённые крупные города.
- Объект Мцхеты включает три компонента; координата относится к собору Светицховели.
- Пафос — серийный археологический объект из трёх компонентов; в seed включён городской компонент Kato Paphos, а не отдельная удалённая компонента Kouklia.
- Для Баку и Валлетты координаты представляют охраняемое историческое ядро.
- Все категории выбраны из существующего справочника; структура категорий не расширялась.
