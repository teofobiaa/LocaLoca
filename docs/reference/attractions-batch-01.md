## Принципы отбора и проверки

Для первой партии выбраны объекты из разных регионов мира, включённые в Список всемирного наследия ЮНЕСКО. Описания и исторические сведения пересказаны по страницам Центра всемирного наследия. Координаты взяты из опубликованных ЮНЕСКО географических данных объекта и переведены из градусов, минут и секунд в десятичный формат с округлением до 6 знаков после запятой.

Координаты ЮНЕСКО могут обозначать репрезентативную точку объекта или центра охраняемой территории, а не вход для посетителей. Для крупных исторических территорий это важное ограничение; в следующих партиях для точек входа и отдельных зданий предпочтительны официальные планы/карты объекта.

## Примечания к географической привязке

- Айт-Бен-Хадду — населённый пункт/ксар, а не крупный город; он указан как локальность объекта, чтобы не привязывать достопримечательность к удалённому административному центру.
- Петра — археологический город рядом с современным Вади-Муса; в справочнике городов используется Вади-Муса как ближайший современный населённый пункт для туристического доступа.
- Для крупных исторических территорий (Старый Квебек, исторический центр Кракова, Аюттхая) координаты ЮНЕСКО представляют точку охраняемого объекта, а не адрес конкретного здания.
