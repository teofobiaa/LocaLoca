## Принятый стандарт

**195 государств: 193 государства — члена ООН + 2 государства-наблюдателя при ООН: Государство Палестина и Святой Престол.**

Список не включает зависимые территории, автономные образования и территории со специальным статусом, не входящие в этот стандарт. Для Святого Престола используется именно международно-правовое наименование «Святой Престол»; «Ватикан» — распространённое обозначение территории/государства-города, но не название наблюдателя ООН.

Основание: список ООН/UNGEGN, содержащий 193 государства-члена и двух наблюдателей; справочник ООН подтверждает, что двумя государствами-наблюдателями являются Святой Престол и Государство Палестина.

## Правила дальнейшего наполнения

1. Не удалять, не пересоздавать и не переименовывать 19 существующих стран.
2. Не менять их `country_id`.
3. Добавлять только отсутствующие страны.
4. Использовать уникальность по названию (и, если схема будет расширена, по ISO-коду); повторный запуск seed не должен создавать дубликаты.
5. Добавление городов и достопримечательностей вести отдельными этапами. Наличие страны не означает, что для неё уже существуют города или достопримечательности.
