## Методика

Описания и исторические сведения подготовлены по материалам Центра всемирного наследия ЮНЕСКО. Координаты взяты из географических данных UNESCO World Heritage Centre и переведены из DMS в десятичные градусы с округлением до 6 знаков. Для охраняемых городских ансамблей и крупных археологических территорий координата является репрезентативной точкой объекта, а не обязательно входом или точкой навигации.

## Географические и классификационные примечания

- Площадь Дурбар Хануман-Дхока — один из семи монументальных компонентов объекта «Долина Катманду», а не отдельный объект Всемирного наследия.
- Для Самарканда взята точка средневекового городского ядра из географической таблицы UNESCO; у объекта несколько компонентов.
- Тикаль — обширный национальный парк и археологическая зона. В качестве локальности указано название самой территории, а не удалённый административный центр Флорес.
- Потоси и Кайруан — исторические городские ансамбли; координаты указывают на репрезентативную часть охраняемого ядра.
- Категории ограничены существующим справочником. Природная составляющая Тикаля не выделяется отдельной категорией, поскольку в каталоге пока нет категории природных объектов.
