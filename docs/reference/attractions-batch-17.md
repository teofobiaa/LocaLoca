## Примечания по координатам

- Одзала-Кокуа: N1 20 8, E14 51 37 — координаты UNESCO для объекта; в базе использована десятичная форма 1.335556, 14.860278.
- Атолл Бикини: N11 35 60, E165 22 50 — координаты UNESCO; точка представляет центр атолла.
- Ватикан: N41 54 7.776, E12 27 26.496 — координаты UNESCO.
- «Тринадцать камней»: N13 17 29, W61 14 52 — координаты объекта из карточки UNESCO.
- Бастер: UNESCO указывает остров Сент-Китс как регион объекта; в базе использована ориентировочная координата центра исторического города (17.295500, -62.724600), а не заявленная UNESCO координата объекта.
- Мейн-Ридж: N11 30, W60 40 — координаты UNESCO для лесного заповедника.
- Нанумеа: S5 40 30, E176 06 56 — координаты компонента серийного культурного ландшафта по карточке UNESCO.
- Монте-Ален: N1 49, E10 15 — координаты UNESCO.
- Нгвеня: -26.197914, 31.082239 — географическая точка шахты из национального экологического документа Эсватини; карточка UNESCO указывает регион Хохо, но не публикует координаты.
- Монте-Кафе: N0 18 02.2, E6 38 23.0 — координаты компонента Monte Café в географической карточке UNESCO.

Категории выбраны из существующего справочника; новые категории не добавлялись. Города/локальности вставляются через `ON CONFLICT (country_id, name) DO NOTHING`, достопримечательности — через `WHERE NOT EXISTS` по паре `city_id + name`.
