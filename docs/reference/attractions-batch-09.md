## Примечания по координатам и статусу

- Маново-Гунда-Сен-Флорис — обширный национальный парк площадью около 1,74 млн га. Координаты UNESCO N9 0 0, E21 30 0 являются ориентиром для территории. Объект находится в Списке всемирного наследия под угрозой с 1997 года; это отражено в описании.
- Для Морн-Труа-Питон использована координата UNESCO N15 19 52.007, W61 18 23.796.
- Для Голубых и Джон-Кроу гор использована координата UNESCO N18 4 39, W76 34 16.
- Иезуитские миссии Парагвая — серийный объект из двух компонентов. В seed координата относится к миссии Ла-Сантисима-Тринидад-де-Парана; второй компонент — Хесус-де-Таваранге.
- Рисовые террасы Кордильер Филиппин — культурный ландшафт из пяти кластеров. Координата относится к кластеру Батад в муниципалитете Банауэ, а не ко всему объекту.
- Для Эз-Зубары использована центральная координата объекта UNESCO N25 58 41, E51 1 47.
- Для Хегры использована координата UNESCO N26 47 1, E37 57 18.
- Для пещер Шкоцян использована координата UNESCO N45 40 0.012, E14 0 0.
- Для Саразма использована координата UNESCO N39 30 28.4, E67 27 31.4.
- Кутаммаку — трансграничный культурный ландшафт Того и Бенина, расширенный в 2023 году. В seed использована координата компонента на территории Того: N10 4 0, E1 8 0.
- Категории выбраны из существующего справочника; новые категории не добавлялись.

## Контроль

До партии: 124 достопримечательности и 99 стран с достопримечательностями.
Добавлено: 10 объектов в 10 ранее не представленных странах.
Ожидается после партии: 134 достопримечательности и 109 стран с достопримечательностями; без достопримечательностей останется 86 стран из 195.

Города вставляются через `ON CONFLICT (country_id, name) DO NOTHING`, достопримечательности — через `WHERE NOT EXISTS` по паре `city_id + name`. Категории используются из существующего справочника.
