# Партия 18 — завершение каталога 195 стран

Дата: 20 ноября 2026 года.

Добавлены последние 6 стран без объектов. После этой партии каталог содержит по меньшей мере одну достопримечательность для каждой из 195 стран справочника. Статусы UNESCO разграничены: Предварительный список (Tentative List), Мировая сеть биосферных резерватов и национальные/локальные достопримечательности — разные категории охраны и признания.

Страница государства в UNESCO подтверждает отсутствие объектов в Tentative List: https://whc.unesco.org/en/statesparties/bn.
- Лихтенштейн, Vaduz Castle: [официальный туристический портал княжества](https://en.tourismus.li/map/poi/schloss-vaduz-8fb7e6cf-99b5-4ffb-b600-9e4c66398e1f.html). Координата в базе ориентировочная для замка; описание и история взяты с официальной страницы.
- Монако, Les Alpes de la Méditerranée: [карточка UNESCO Tentative List №6180](https://whc.unesco.org/en/tentativelists/6180/). Карточка прямо указывает трансграничный характер и морскую часть Монако.
- Науру, Command Ridge: [Commonwealth Walkway — историческое описание](https://commonwealthwalkway.info/place/command-ridge/); [документ по военным объектам Науру](https://nauru-data.sprep.org/system/files/Nauru%20Historical%20Cttee%20%28%20-%20%29%20Nauru%20war%20sites%20and%20relics.pdf). Координата — ориентировочная точка объекта, не геодезическая координата из документа.
- Сомали, Mogadishu Secondo-Lido Lighthouse: [карточка UNESCO Tentative List №6754](https://whc.unesco.org/en/tentativelists/6754/); [сообщение UNESCO о пересмотре Tentative List](https://whc.unesco.org/en/news/2819/); [оценка состояния маяка и исторического района](https://www.unesco.org/en/articles/illuminating-past-mogadishus-lighthouse-leads-heritage-revival-somalia).
- Тимор-Лесте, Nino Konis Santana National Park: [UNESCO — присвоение статуса биосферного резервата](https://www.unesco.org/en/articles/nino-konis-santana-designated-timor-lestes-first-unesco-biosphere-reserve); [официальная туристическая страница парка](https://timorleste.tl/destinations/nino-konis-santana); [государственная система охраняемых территорий](https://snap.mappf.gov.tl/main/detail_menu/19). Координата соответствует точке парка из Coral Triangle Atlas: https://ctatlas.coraltriangleinitiative.org/MPA?id=6000100.

## Примечания

- Бруней не представил объектов в Tentative List UNESCO; Кампонг-Айер выбран как значимый исторический объект, подтверждённый национальным туристическим ведомством.
- Лихтенштейн не является государством-участником Конвенции всемирного наследия UNESCO; Замок Вадуц не маркируется как объект UNESCO.
- Для Монако координата UNESCO указана в порядке долгота/широта; в SQL она преобразована в широту 43.347401 и долготу 7.587207. В описании сохранено уточнение, что вклад Монако в трансграничный объект относится к морской акватории.
- Науру уведомило ООН 26 июня 2026 года о смене официального названия на Республика Наоэро. В SQL сохранено «Науру», поскольку так называется страна в существующем справочнике проекта; переименование страны не входит в задачу этой партии.
- Для маяка Могадишо координаты N2 02 03.6 E45 20 38.8 преобразованы в 2.034333, 45.344111.
- Биосферный резерват Тимор-Лесте не следует называть объектом Всемирного наследия: это отдельная программа UNESCO Man and the Biosphere.

Категории взяты из существующего справочника. Города/локальности вставляются через `ON CONFLICT (country_id, name) DO NOTHING`, достопримечательности — через `WHERE NOT EXISTS` по паре `city_id + name`.
