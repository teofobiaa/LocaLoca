## Примечания по координатам и классификации

- Для Минарета Джам использованы координаты самого минарета из периодического отчёта UNESCO; это не координаты центра всей долины.
- Калат-аль-Бахрейн и Мирский замок представлены точками археологического/архитектурного комплекса.
- Барьерный риф Белиза — серийный объект из семи охраняемых участков. Координата относится к Blue Hole Natural Monument, одному из компонентов; объект был исключён из Списка всемирного наследия под угрозой в 2018 году.
- Координаты Лопе-Оканда относятся к одному из компонентов обширного природно-культурного объекта.
- Координата традиционных зданий Ашанти — репрезентативная точка группы памятников рядом с Кумаси.
- Координаты Тимбукту и Бриджтауна относятся к охраняемому историческому ядру.
- Для острова Мозамбик использована точка UNESCO для основного островного компонента.
- Категории выбраны из существующего справочника; новые категории не добавлялись.

## Контроль

До партии: 114 достопримечательностей и 89 стран с достопримечательностями.
Добавлено: 10 объектов в 10 ранее не представленных странах.
Ожидается после партии: 124 достопримечательности и 99 стран с достопримечательностями; без достопримечательностей останется 96 стран из 195.

Города вставляются через `ON CONFLICT (country_id, name) DO NOTHING`, достопримечательности — через `WHERE NOT EXISTS` по паре `city_id + name`. Категории используются из существующего справочника.
